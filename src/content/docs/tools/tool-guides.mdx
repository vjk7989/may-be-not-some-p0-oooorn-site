## Hyper Tern

Place Hyper Tern between a proposed agent action and the downstream tool. Supply structured identity, purpose, target, operation, data scope, and limits. Treat allow, deny, and approval as explicit policy outcomes.

## Hyper-ABS

Place Hyper-ABS before the model endpoint. Classify and minimize inputs, apply masking where appropriate, and route each data class only to an approved endpoint. Continue to enforce access control and output checks elsewhere in the workflow.

## Hyper-0x

Send structured policy, approval, execution, and result evidence to Hyper-0x. Keep sensitive payloads off broadly replicated records. The ledger supports verification, audit, and settlement; it does not provide confidentiality or prove model truth.

## Hyper Wallet

Hyper Wallet is available now as an agent credential wallet for identity, credentials, policy-bound permissions, and delegated approvals. Use short-lived, revocable grants tied to a specific task. It is not a digital-asset custody or payment product and does not guarantee secure outcomes.
